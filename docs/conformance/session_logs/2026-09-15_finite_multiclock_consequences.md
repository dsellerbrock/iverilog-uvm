# L100 — Finite multiclock consequence alternatives

IEEE 1800-2017 and 1800-2023 16.9.2, 16.12.7, 16.12.22 and 16.13.2 distinguish existential alternatives within a consequence from the obligations produced by every antecedent match. Previously an internal finite range in a second-clock consequence was rejected even when a later alternative could succeed after the early alternative failed.

The parser lowering reuses the existing finite acyclic NFA builder and parent START/MATCH/CLOSE transport. Each antecedent child carries its own consequence mask in the existing age-indexed tag queues. First acceptance completes that child once; exhaustion fails it once. The existing parent aggregator requires every child. Fixed antecedents enter the same transport only when the consequence needs the new NFA path; existing fixed/trailing-window paths remain intact.

Focused tests distinguish early acceptance, late acceptance, all-dead failure and divergent sibling outcomes. They check both implication forms, coincident clock process order, fixed prefixes, Off, Kill, asynchronous disable/restart, a paused destination with multiple parents, one cover verdict, empty-antecedent handoff and depth boundaries. Previously rejected internal-range and nested-range cases now have exact runtime witnesses in both editions, preserving their historical test names.

The [validation record](2026-09-15_finite_multiclock_consequences_validation.json) records the tested source, binaries and harnesses. Broad batch qualification remains pending. The existing 64-tick finite construction limit is an implementation boundary, not an IEEE restriction or a pending-parent limit. Unbounded/cyclic operands, match actions, local-variable merges and plain multiclock sequences requiring this new consequence transport remain unsupported.

Failed evidence is retained. The first candidate exposed a borrowed-expression alias during fixed-antecedent promotion; clearing the obsolete slot view repaired the ownership error. The backlog stimulus originally changed an operand in the same Active slot as its sampling edge; moving the stimulus before the edge preserves required Preponed sampling. The first disable witness included an unrelated vacuous pass; Off/On now isolates the canceled obligation and fresh attempt while retaining the between-edge reset pulse. A stale standalone 2023 negative fixture was replaced with the paired terminating runtime witness before validation.
