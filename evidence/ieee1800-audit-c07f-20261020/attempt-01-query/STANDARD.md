# IEEE 1800 §20.7 and §20.7.1 text reviewed

- IEEE 1800-2017 §20.7, pp. 600–602; IEEE 1800-2023 §20.7, pp. 630–631: `$dimensions` returns the total dimensions of an array and `$unpacked_dimensions` its unpacked dimensions; a simple integral type contributes one dimension. Dimensions are numbered slowest-varying first, with an integer type's predefined packed dimension included.
- Both editions §20.7: for a fixed-size dimension, `$increment` returns 1 when left ≥ right and −1 when left < right; for queues and dynamic arrays it returns −1. `$size` is the number of elements in the selected dimension.
- Both editions §20.7: an array-query call returns `'x` if the first argument has no dimensions or the optional dimension argument is out of range. Array queries on associative-array dimensions are restricted to integral index types; for integral indices, `$left` is 0, `$right` is the highest possible index, `$low`/`$high` are the least/greatest allocated keys (or `'x` when empty), `$increment` is −1, and `$size` is the number allocated.
- Both editions §20.7: queries may be used in constant expressions when the call and type operator are legal for a fixed-size type and the optional dimension is constant. The standard's `Word`/`Ram` example returns 16 for both `$size(Word)` and `$size(Ram,2)`.
- Both editions §20.7.1: for a variable array `v`, a query with dimension `n > 1` is an error if dimension `n` is variable-sized. The standard's `int a[3][][5]` example shows `$size(a,2)` as an error, `$size(a,3)` as 5, and querying `a[2]`'s dynamic dimension as 4 after allocation.
