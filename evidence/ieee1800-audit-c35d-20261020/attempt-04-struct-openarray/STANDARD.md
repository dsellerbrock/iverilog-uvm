# Standard basis

IEEE 1800-2017 and 1800-2023 §35.5.6.1 allow imported-function open-array
formals to match actual arrays regardless of the corresponding dimension's
range. Annex H.7.8 expressly includes unpacked structures and arrays of
unpacked structures as DPI aggregate types when their element types are legal
basic types. `int` is a legal basic type per Annex H.7.4/Table H.1.

The probe asks only for the open-array handle's dimension and size.
