# Standard basis

Checked in IEEE 1800-2017 and IEEE 1800-2023.

- §35.5.6.1 specifies open-array arguments for DPI imports.
- Annex H.10.1–H.10.3 defines the relevant `svdpi.h` query, element-access,
  and array-access APIs exercised by these existing tests.
- The probe covers supported atom/real, dynamic-array and fixed-range cases;
  it does not establish all element types or all legal array shapes.
