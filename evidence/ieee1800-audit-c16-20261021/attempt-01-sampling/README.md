# Clause 16.5.1 sampled-value depth probes

Scope: IEEE 1800-2017 and 1800-2023 §16.5.1 (2017 printed pp.374–375; 2023 printed pp.393–394). The sampled-value requirements are the same; only a cross-reference number changes.

S1/S2 compare sampled values with NBA and blocking updates; S3a–e check time-zero default sampling and whether a concurrent assertion attempt occurs at t=0; S4 checks assertion action-block scheduling; S5 checks a function argument. S6 cannot reach the sampling rule because the `const'` cast fails to parse in every context; see issue [#910](https://github.com/dsellerbrock/iverilog-uvm/issues/910). The S3c `cover property` pass action is dropped with a warning; see [#911](https://github.com/dsellerbrock/iverilog-uvm/issues/911). Assert pass actions work in S7. All assertion cases compile with `-gassertions` in both editions.
