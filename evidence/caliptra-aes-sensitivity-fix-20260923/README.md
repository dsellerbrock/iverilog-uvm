# Function-local `always_comb` sensitivity fix

The [paired pre-fix reducer](../caliptra-aes-timezero-20260923/README.md) spun at time zero in 2017 and 2023 when two `always_comb` callers read an automatic function local written one bit at a time. `NetBlock::nex_input` subtracted those precise output intervals from a whole-vector read with exact-match `NexusSet::rem`, leaving the local in both implicit event sets.

The candidate uses interval-aware subtraction only for the `always_comb` sensitivity calculation. Exact `rem` semantics for event-expression matching remain intact. [Focused results](results.json) pass 8/8 paired candidate cases, including a partial-write/read boundary, the former RED, one-caller, and whole-vector controls. Focused synthesis checks pass 10/10 legacy and 8/8 JSON, including `sv_synth_event_clock_coexist` in both editions. A [strict full-top replay](../caliptra-icarus-l0-strict-sensitivity-20260923/summary.json) still rejects all 46 mixed-driver overlaps. A [copied-reset unsafe runtime](../caliptra-icarus-l0-diagnostic-aesfix-first-20260923/summary.json) advances to 43.865 us and 621 instruction-trace entries before separate assertions fail; it is 0/1, not an L0 pass.
