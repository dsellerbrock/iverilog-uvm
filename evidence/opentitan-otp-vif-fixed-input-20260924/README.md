The pinned OTP `otp_ctrl_base_vseq.sv:411` calls an automatic interface task through a class-held virtual interface with a fixed unpacked-array input. Before this change, Icarus rejected that legal call with a `sorry`. The paired 2017/2023 RED matrix contains 20 cases: 16 compile failures, including the legal call, and four passing runtime controls. `elaborate.cc` now admits only one-dimensional packed-integral fixed-array **input task** formals, then checks each selected candidate's whole-array actual and equivalent element shape before existing VVP copy-in. A two-instance runtime checks selection, element order, four-state values, and caller isolation for automatic and static tasks. Wrong size, type, scalar actuals, omitted/default arrays, output/inout/ref, multidimensional arrays, and fixed-array functions remain rejected.
