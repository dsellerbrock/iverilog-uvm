# OTP fixed parameter-member constraint

The released `otp_ctrl_smoke_vseq` uses package `localparam PartInfo[]` entries in eleven conditional `dai_addr inside` ranges. Before this change, constraint lowering discarded those ranges and emitted only `solve part_idx before dai_addr`. The paired 2017/2023 reducer then accepted out-of-range addresses; a missing struct member also compiled with an ignored-item warning. Scalar aliases to the same endpoints worked, isolating the front-end parameter-member conversion rather than the solver.

`elaborate.cc` now uses ordinary parameter-member elaboration after proving the lexical parameter root and every array index constant under constraint lookup. It resolves this before a same-named terminal class property. A member with meaningful bits above bit 63 is diagnosed instead of truncating into the compact constraint IR. Rand-indexed `PartInfo[part_idx].secret` is not frozen. Paired legal, endpoint, adjacent-invalid, rollback, property-shadow, explicit-package, absent-member, and wide-value controls are in `ivtest`.

The private Icarus image compiles the exact pinned OTP program with all eleven address ranges present. The low and high native-DPI replays finish at 141094616 ps with `TEST PASSED CHECKS`, no UVM warning/error/fatal or assertion errors, and 1343 checked TL A plus 1343 checked TL D items. The high replay makes one DAI attempt at `0x658` in partition 4, inside the emitted `0x650..0x670` range. This is **diagnostic runtime progress, not a qualified released DV pass**: `dai_wr_blank_addr_c` still drops the distinct rand-indexed `.secret` condition, and six covergroup bins are dropped. Released OTP DV remains **0/1**. The existing hash-checked RAM-path overlay applies only to a disposable generated source copy; the pinned OpenTitan checkout and native DPI remain unchanged.

The paired strict reducers exercise IEEE 1800-2017/2023 aggregate parameters (§§6.20.2, 6.20.4), packed-struct members (§7.2.1), `inside` ranges (§11.4.13), and conditional constraints (2017 §18.5.7; 2023 §18.5.6). They are separate from the pinned `-g2012` release replay. Both focused harnesses pass 6/6; broad legacy has 6626 total with zero unexpected failures, JSON 3667/3667, negatives 155/155, SVA dual-engine 62/62, VPI 140/140, and real-DPI UVM 358/358.
