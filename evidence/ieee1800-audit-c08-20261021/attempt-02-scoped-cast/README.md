# §8.5 / §6.24.1 scoped-type cast probes

Five isolated cases test a typedef control, explicit parameterized class scope, empty/default class specialization, an unparameterized class scope, and a package scope cast. Each ran in both `-g2017` and `-g2023`. The expected value is 1 after casting 9 to a 3-bit type. See `STANDARD.md` and `RESULT.md`.
