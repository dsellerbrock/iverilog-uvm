# OTP covergroup constructor method endpoints

The pinned `otp_ctrl_smoke_vseq` uses six `csr_rd_after_alert_cg` bins with 36 `ral.<register>.get_offset()` endpoints. Before this change, Icarus dropped all six bins at compile time. Paired 2017/2023 direct and signed reducers compiled with a dropped-bin diagnostic and then failed at runtime; a mutable method default was also accepted without a purity proof. The baseline commands, tool hashes, and outputs are in `baseline.result.json`.

The covergroup constructor now captures supported method endpoints once per instance, after its ordinary arguments and before VVP resolves dynamic bins. Strict mode proves the direct non-ref formal, method body, and effective default arguments; unresolved or illegal forms reject. It currently rejects nested receiver paths as **unproven**, without claiming that IEEE forbids every such path. `-gcommercial-unsafe` permits the pinned nested RAL path with an explicit nonstandard warning and no purity proof. Side-effecting methods are possible under that opt-in flag; this result is not IEEE conformance evidence. Null or X/Z endpoints fail loudly. Focused positive, negative, and boundary controls pass 34/34 in both the legacy and JSON harnesses across 2017 and 2023.

On the final private Icarus image, the exact pinned OTP compatibility compile has no dropped bins or ignored constraint items. Its VVP descriptor retains all 36 endpoints in the six original groups. The native-DPI smoke completes at 141094616 ps with one `TEST PASSED CHECKS`, zero UVM warnings/errors/fatals or assertion errors, one DAI attempt at `0x66c` in partition 4, and 1343 checked TL A plus 1343 TL D transactions. This is **1/1 released OTP DV in the nonstandard compatibility lane**. The strict pinned compile rejects 36 nested receiver endpoints and has no released runtime. A retained bin descriptor does not prove a functional bin hit in this smoke; the covergroup samples only under its original alert/coverage guard.

The compile retains 40 preexisting `force` RHS support warnings in the OTP fault-injection task. All ten logged partition injection selectors are zero in this seed, so those warned branches were not exercised. This 1/1 result does not qualify other seeds that exercise them. The original checks and pinned OpenTitan checkout were unchanged; the existing RAM-path overlay was applied only to a disposable generated source copy. Exact input and tool hashes, commands, logs, and qualification criteria are in the adjacent files. Repository gates and other OpenTitan tests have separate denominators.
