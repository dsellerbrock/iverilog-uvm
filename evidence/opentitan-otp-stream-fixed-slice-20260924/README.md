# OpenTitan OTP fixed-array streaming slice

The pinned Earlgrey-PROD-M6 source (`a78922f14a8cc20c7ee569f322a04626f2ac6127`) uses seven direct streaming operands of the form `{<<32 {otp_a[base +: count]}}` in `otp_ctrl_scoreboard.sv`. `otp_a` is a fixed unpacked **class property**. The prior compiler reported `Array cannot be indexed by a range` at lines 168, 175, 198, 200, 201, 227, and 238. A reducer using a module array alone missed the class-property path; paired 2017/2023 property reducers reproduced it before the fix.

`elab_expr.cc` now packs a constant one-dimensional fixed-array slice in its selected left-to-right order using the existing fixed-slice decoder. Property reads use the array's declared low bound for their canonical index. `<<32` reverses 32-bit chunks; `>>32` preserves them. The property path and the pre-existing whole-array streaming path now apply the ordinary modport member-access check. Paired reducers showed that both restricted-modport reads previously compiled, while ordinary reads of the same unlisted member rejected. The new tests check valid ascending/descending values, explicit and implicit class receivers, an illegal reverse-direction slice, valid readable/unrestricted modports, and rejection of unlisted slice and whole-array members. Width and property-index limits reject loudly before narrowing.

The final private compiler is SHA-256 `16ea00bf6706be70e185a77d05dcdd0a3f4722da76da4c4dcf25cef4936916c5`. It is not installed; live Caliptra jobs still use installed `ivl` SHA-256 `6ec92c4825dc51e3810d1cb22405071f033015626d39cf3db92c319aeb9d3b10`. Focused 2017/2023 compile/runtime controls pass 12/12, including the expected compile errors. The registered JSON focus passes 10/10. Full-suite results and exact log hashes are in `result.json`.

The exact pinned OTP recompile now reports **16** explicit errors and exits 17, versus **23** explicit errors and exit 24 on the immediately preceding private compiler. Its seven targeted stream errors are gone. Other OTP errors remain, including five slice-to-queue assignments, packed-parameter `foreach`, virtual-interface array marshalling, and strict mixed drivers. The pinned `chip_sim` compile remains at 48 explicit errors and aborts at `entropy_src_core.sv:3324` (`base < vwid`). Neither application reaches DV runtime from these compiles. The pinned source tree is unchanged.

This increment covers a direct constant slice of a one-dimensional fixed array as the streaming operand. A slice nested among multiple ordinary stream operands, or a pre-sliced operand followed by `with`, remains outside this increment. Constant out-of-range values retain the existing loud implementation boundary; they are not labeled IEEE-illegal here. These are IEEE-focused compiler checks, separate from Caliptra's explicit nonstandard `-gcommercial-unsafe` compatibility lane and its selected-52 runtime numerator.
