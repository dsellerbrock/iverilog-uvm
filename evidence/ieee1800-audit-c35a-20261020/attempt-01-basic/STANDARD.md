# Clause 35 scope and probe references

The two editions have the same direct subclause titles. IEEE 1800-2017's table of contents lists Clause 35 on p. 938; IEEE 1800-2023 lists it on p. 970.

| §35.7 | Exported functions | 950 | 982 |

The basic probe exercises a scalar function import, real function import, string function import, output argument, exported function, and context import calling back into that export. Its direct scope is IEEE 1800-2017/2023 §§35.5–35.7. It does not assess imported tasks, exported tasks, disable semantics, or the full DPI type/ABI matrix.
