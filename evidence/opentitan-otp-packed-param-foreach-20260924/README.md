# OpenTitan OTP packed-parameter `foreach`

Pinned Earlgrey-PROD-M6 (`a78922f14a8cc20c7ee569f322a04626f2ac6127`) declares `FATAL_EXP_STATUS` as a packed parameter in `otp_ctrl_env_pkg.sv:72` and iterates it in `otp_ctrl_scoreboard.sv:294`. The prior private Icarus compiler rejected it as “not an unpacked array parameter.” Paired 2017/2023 reducers cover descending and ascending nonzero bounds, a one-element `[0:0]` vector, and untyped integral and sign-only parameters. IEEE 1800-2017/2023 §§6.20.2 and 12.7.3 give those last forms an inferred packed logic-vector range and allow `foreach` over packed arrays. Explicit scalar `bit` and built-in `int` atom controls remain compile errors.

`PForeach::elaborate()` now passes evaluated packed parameter bounds to the existing static-array loop builder after the unpacked-parameter path. For sign-only parameters, it uses the inferred value width, as the existing parameter-select code does. The branch excludes built-in integral atom types, whose internal width ranges do not make them arrays. It changes no runtime opcode or pinned application source.

The final private compiler image and suite hashes are in `result.json`; it is not installed while Caliptra simulations use the shared compiler.
