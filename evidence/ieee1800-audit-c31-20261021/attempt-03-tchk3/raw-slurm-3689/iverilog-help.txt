Usage: iverilog [-EiRSuvV] [-B base] [-c cmdfile|-f cmdfile]
                [-g1995|-g2001|-g2005|-g2005-sv|-g2009|-g2012] [-g<feature>]
                [-D macro[=defn]] [-I includedir] [-L moduledir]
                [-M [mode=]depfile] [-m module]
                [-N file] [-o filename] [-p flag=value]
                [-s topmodule] [-t target] [-T min|typ|max]
                [-W class] [-y dir] [-Y suf] [-l file] source_file(s)
                [-uvm] [--uvm-home=dir] [--uvm-no-dpi] [--uvm-version]
                [--uvm=version] [--uvm-list]

  -uvm            Enable the supported UVM environment: add the installed
                  UVM sources and DPI runtime automatically.
  --uvm=version   Select an acquired UVM release.
  --uvm-list      List available UVM releases and exit.
  --uvm-home=dir  Use the UVM library at dir instead of the bundled one.
  --uvm-no-dpi    Compile UVM's pure-SystemVerilog fallbacks (no DPI).
  --uvm-version   Print the bundled UVM version and exit.

See the man page for details.
