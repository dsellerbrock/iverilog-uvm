# IEEE 1800 §§14.10–14.11 probe run

Source is pinned to clean `origin/main` commit `c31cbf1b52f1a39d5775f276e2340525a444a79e`. The probes exercise waiting on a clocking block event, procedural cycle-delay forms (`##1`, `##3`, `##n`, and `##(n+1)`), bare `##0` and parenthesized `##(0)` suspension before the next event, `##0` after an event already occurred, and rejection of cycle delay without a default clocking or inside an intra-assignment delay. Both `-g2017` and `-g2023` are required.

Standard references: IEEE 1800-2017 §§14.10–14.11 (p. 342; §14.11 continues on p. 343) and IEEE 1800-2023 §§14.10–14.11 (pp. 360–361). The editions differ in the `##` count rule: 2017 specifies positive integer expressions but separately defines bare `##0`; 2023 explicitly permits non-negative expressions, including `##(0)`. The edition-paired probes distinguish acceptance from the required suspension semantics.

The source archive is reused from the §14.6–§14.7 run: SHA-256 `fb22d029cef3f9fa504bd5831a991b64755bcc449e2a80d75258a90096ba363c`. Jobs 3164 and 3165 were canceled while dependency-pending after the probe set was expanded; replacement job 3166 waited on `afterany:3161`. It used 2 CPUs / 3 GiB to build source commit `c31cbf1b52f1a39d5775f276e2340525a444a79e`; executable hashes and all test output are preserved under `results/` and `logs/`.

Job 3166 completed all probes. `p14_10_clocking_event`, ordinary positive cycle delays, `##0` after the associated event, and both required compile-time rejections passed in both editions. The expected pre-event `##0` suspension failed in both editions: the calling process finished at 2 ns instead of waiting for the event at 5 ns. `##(0)` also ran before the event rather than suspending; it was accepted in 2017 although that edition requires expression-valued delays to be positive, and it failed the required zero-delay behavior in 2023.
