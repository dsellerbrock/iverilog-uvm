#760 [OPEN] [IEEE 1800] §6.18 — class-scope type selection through a forward-declared class (typedef C::T) is rejected
**Clause:** 2017 §6.18 p.113 / 2023 §6.18 p.118.
**Normative:** "use of the class scope resolution operator (see 8.23) to select a type with such a prefix shall be restricted to a typedef declaration." Example: `typedef C; typedef C::T c_t; // legal; reference to C::T is made by a typedef`.
**Probe:** tests/1800_audit/c06/p06_18d_forward_class_scope.sv (the standard's example verbatim).
**Observed:** `typedef C; typedef C::T c_t; c_t y; class C; typedef int T; endclass` fails with "C doesn't name a visible class." The `typedef class Node;` forward form and coupled class definitions work (p06_18c_coupled_class prints NODE=7), as do enum, struct, union, class and untyped forward typedefs (p06_18b_forward_kinds).
**Expected:** the typedef through the forward-declared class resolves after C is defined; `$bits(y) == 32`.
