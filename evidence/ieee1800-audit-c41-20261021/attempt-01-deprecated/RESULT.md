# Clause 41 review

IEEE 1800-2017 and IEEE 1800-2023 §41 both say the Data Read API clause is deprecated and direct readers to IEEE 1800-2005 for its contents. The clauses contain no active requirements to probe. See [STANDARD.md](STANDARD.md) for the direct extracts and printed page numbers and [DEDUPE.md](DEDUPE.md) for the open-and-closed issue search.
