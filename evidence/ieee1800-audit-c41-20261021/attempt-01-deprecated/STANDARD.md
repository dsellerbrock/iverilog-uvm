# Clause 41 status in IEEE 1800-2017 and IEEE 1800-2023

Both editions contain the same Clause 41 text:

> This clause has been deprecated. See IEEE Std 1800-2005 for the contents of this clause.

- IEEE 1800-2017 §41, printed p. 1134.
- IEEE 1800-2023 §41, printed p. 1170.

This is a direct extract from each edition's PDF. The clause gives no active requirements to probe in either edition.
